# Self-Hosted Compiler Feature Matrix

The Rust column describes the current stage0 compiler. The self-hosted column
tracks what the Mimi implementation supports. A feature is complete only when
the Python suite covers it through the self-hosted compiler.

| Area | Current Rust compiler | Mimi implementation | Verification |
| --- | --- | --- | --- |
| Dynamic arrays, byte buffers, maps, arena | Supported by Rust standard library | U64 vector, byte buffer, string-to-u64 map, and arena allocation through C runtime | `tests/vector.mi`, `tests/bytes.mi`, `tests/map.mi`, `tests/arena.mi` |
| File, path, directory, process APIs | Supported by Rust standard library | Binary read/write, existence/type/size checks, directory creation, and argv-based process execution | Python integration tests |
| Result and Option | Rust `Result`/`Option` | Generic enum conventions with explicit `match` propagation | `tests/result.mi` |
| Source files and diagnostics | Compiler source map and diagnostics | File loading, canonical relative `@import` discovery (including root-directory modules), iterative depth-first traversal, cycle detection, source spans, and rendered diagnostics | Python source and module graph integration tests |
| Identifiers, numbers, strings, character literals, punctuation | Supported | Slice and raw-buffer token APIs with token spans, escape decoding, decimal/member-number distinction, and single-byte character literals (error code 6 for malformed ones); identifier codepoints use complete Rust Alphabetic/Alphanumeric property tables generated by `tools/generate_unicode_tables.rs` | `tests/lexer.mi`, module graph integration |
| Comments and lexical errors | Supported | Line/block comments, categorized errors, and one result with exact token/error byte spans | `tests/lexer.mi` |
| Source spans and diagnostics | Supported | Span records and source line/caret rendering | Python source model integration test |
| Declarations, functions, modules | Partial | Module ASTs compose bindings, functions, structs, enums, extern functions, `@import`, `@cimport`, and `@cDefine`, including public declarations; duplicate names are rejected; function/method bodies contain recursive statement lists; module-aware lowering covers public functions, plain struct types, and specialized generic enum types across imports; broader generic specialization remains pending | `tests/parser.mi`, `test.py` module checks |
| Scalar, pointer, array, slice, tuple, function types | Supported | Named and module-qualified pointer, slice, fixed-array, nested tuple, nested function, and generic application syntax parsed into arena nodes with source spans; function type parameter lists reject trailing commas like stage0; generic declarations and semantic validation pending | `tests/parser.mi` |
| Expressions, casts, calls, member/index/slice access | Supported | Number/string/boolean atoms retain exact source payload spans; plain and embedded if/else, generic/simple-name struct literals with duplicate-field rejection, tuple literals with arbitrary parsed expression items, and scalar/pointer/generic/tuple casts have dedicated parsers; grouped unary/binary expressions with precedence, negation, logical not, address/dereference, member access, indexing, slices, nested calls, and casts at postfix precedence | `tests/parser.mi` |
| If/match, loops, ranges, break/continue, defer | Partial | `if`/`else if`/`else`, enum `if` variant tests, `while`/`loop`/`do-while`, integer-range and byte-slice collection `for`, exhaustive matches with identifier scrutinees, scoped expression/block `defer`, trailing `if`/`else` block values, and all-paths-return bodies run through the C backend | `tests/parser.mi`, `tests/collection_for.mi`, `tests/enum_if_let.mi`, `tests/enum_match_statement.mi`, `tests/defer.mi` |
| Structs, enums, generics, closures | Supported | Plain struct literals, fields, methods, and pointers plus specialized generic enums with tested scalar payloads; generic structs and closures remain unsupported | `tests/result.mi`, `tests/enum_local.mi`, `test.py` module checks |
| Name resolution and type checking | Supported (stage0); partial (self-hosted) | Stage0 resolves module-level variables and constants, enforces mutability, and checks structured values, calls, generics, and C signatures. The self-hosted pass resolves module, parameter, and local names with source-spanned errors, but calls, member access, aggregates, and generics remain unchecked until lowering | `tests/semantic.mi`, Rust `tests/type_checker` |
| MIR/LIR lowering and register allocation | Partial | Arena-backed typed IR for scalar and aggregate expressions, imports, structs, tuples, specialized enums, control flow, and byte slices; exact integer widths, general aggregates/generics, and register allocation remain pending | `tests/ir.mi`, `test.py` stage1 checks |
| x86_64 and AArch64 code generation | Supported | C backend compiles scalar functions and calls via host `cc`; direct machine-code backends pending | `test.py` scalar and stage1 checks |
| C imports, ABI shims, native linking | Partial | Stage1 links scalar C output and direct scalar `extern` calls through `cc`; C imports, pointer ABI, and callbacks pending | `test.py` stage1 checks |
| Build and C-import caches | Build cache supported | Self-hosted `build` does not yet cache outputs or implement C import caching | Pending |
| Stage1/stage2 bootstrap | Stage0 builds stage1 | Stage1 builds stage2, and both pass the Python behavior suite; same-path stage1/stage2 output hash matches in a local check | `bootstrap.py`, `test.py` |
